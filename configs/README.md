# Конфигурации

| Файл | Содержание |
|---|---|
| `model.json` | Размер ALIF-ядра, входные проекции, входная проекция, prediction head; один MSE следующего входного кода |
| `memory.json` | Кальциевая память, EMA trace и inhibitory gating |
| `conditions.json`, `.csv` | 40 базовых наборов параметров: группа × модель × карта; для новой постановки выполняется tune |
| `maps.json` | Свободные клетки, стены и seed четырёх карт |
| `study.json` | Эпизоды, лимит шагов, evaluation, seed, метрики и статистический протокол |
| `tuning.json` | Начальные motor/prediction параметры и стадии поиска |

`conditions.json` задаёт параметры `run`. `tune` генерирует кандидатов детерминированно, выполняет заданные стадии и сохраняет выбранные параметры в каталоге результатов.

Архитектура SNN задаётся `model.json`; моторная голова всегда состоит из четырёх прямых Motor LIF. Обучающие параметры и расписания берутся из соответствующего условия. Настройки памяти задаются `memory.json`, затем параметры tau/gain/threshold/contrast из условия заменяют соответствующие значения.

При изменении параметров используйте новый каталог `--output`. Runner проверяет совпадение сохранённого протокола и параметров при продолжении расчёта.
